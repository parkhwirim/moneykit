# 🪙 머니킷 (MoneyKit) - 프리랜서 종소세 & 절세 복리 계산기

> **Google AdSense 수익화 최적화 마이크로 금융 웹 서비스**  
> 프리랜서 3.3% 실수령액/종소세 환급 시뮬레이터 및 연금저축·ISA 복리 절세 계산기

---

## 🚀 탑재된 핵심 기능

1. **💼 3.3% 프리랜서 종소세 & 실수령 계산기**
   - 월/연 수입에 따른 당월 3.3%(국세 3% + 지방소득세 0.3%) 원천징수 실수령액 실시간 산출
   - 업종별 단순경비율(IT 개발 64.1%, 크리에이터 등) 기반 5월 종합소득세 과세표준 및 산출세액 모의 계산
   - 기납부세액과 최종 결정세액 비교를 통한 **예상 환급액(+) / 추가납부액(-)** 시각화

2. **📈 연금저축 & ISA 절세 복리 계산기**
   - 월 적립액, 투자 기간, 예상 수익률(S&P500 등) 인터랙티브 슬라이더
   - 연간 최대 600만 원 한도 16.5% / 13.2% 세액공제 환급금 계산
   - 일반 계좌(15.4% 배당소득세 매년 차감) vs 절세 계좌(과세이연 복리) 자산 격차 Chart.js 그래프 시각화

3. **📖 절세 가이드 & FAQ (구글 애드센스 심사 통과 핵심 콘텐츠)**
   - 프리랜서 3.3% 종소세 환급 원리 및 필수 업무 경비 인정 항목 정리
   - 연금저축펀드 vs IRP vs ISA 3대 절세 계좌 비교표 완비

4. **💰 구글 애드센스(Google AdSense) 최적화 세팅**
   - 상단 리더보드, 결과 하단 인라인, 푸터 상단 광고 슬롯 배치 완료
   - 애드센스 필수 승인 요건: **개인정보처리방침(Privacy Policy) & 이용약관(Terms)** 모달 탑재
   - 서버 통신 없는 100% 클라이언트 브라우저 로컬 연산 (개인정보 수집 0건)

## 🌐 무료 1분 배포 방법 (서버 비용 0원)

### 방법 1: Vercel (가장 추천)
1. [vercel.com](https://vercel.com) 로그인 (GitHub 연동)
2. `tax-calculator` 폴더를 GitHub 레포지토리에 올린 뒤 Import
3. 배포(Deploy) 클릭 시 **30초 만에 무료 HTTPS 도메인** 발급 완료!

### 방법 2: GitHub Pages
1. GitHub 새 레포지토리 생성 후 `index.html` 업로드
2. `Settings > Pages > Branch: main` 선택 후 저장
3. `https://<아이디>.github.io/<레포지토리명>`으로 즉시 서비스 오픈!
